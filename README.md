# Site Dr. Gabriel Paulo Rockenbach

Site institucional proprietario do Dr. Gabriel Paulo Rockenbach, cirurgiao-dentista e especialista em Ortodontia em Ijui/RS.

Dominio canonico:

https://dentistagabrielrockenbach.com.br/

Se a versao com www estiver ativa, configure redirecionamento 301 para o dominio canonico sem www.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Producao

```bash
npm run build
npm run seo:audit
```
