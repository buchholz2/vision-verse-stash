# Search Console Checklist

1. Criar propriedade no Google Search Console:

https://dentistagabrielrockenbach.com.br/

Preferência: criar uma propriedade de domínio para cobrir raiz e `www`. Se usar propriedade por prefixo de URL, criar pelo menos a versão canônica sem `www`.

2. Verificar propriedade.

3. Enviar sitemap:

https://dentistagabrielrockenbach.com.br/sitemap.xml

4. Usar inspeção de URL e solicitar indexação para:

https://dentistagabrielrockenbach.com.br/

https://dentistagabrielrockenbach.com.br/ortodontista-em-ijui

https://dentistagabrielrockenbach.com.br/invisalign-em-ijui

https://dentistagabrielrockenbach.com.br/aparelho-transparente-em-ijui

https://dentistagabrielrockenbach.com.br/dentista-em-ijui

5. Depois de alguns dias, conferir:

- se as páginas foram descobertas;
- se foram indexadas;
- se há erro de canonical;
- se há erro de robots;
- se há erro de sitemap;
- se há problema de mobile usability;
- se há Core Web Vitals disponíveis.

## Observação sobre www

O sitemap e os canonicals usam somente:

https://dentistagabrielrockenbach.com.br/

Se `www.dentistagabrielrockenbach.com.br` estiver ativo, configurar redirecionamento 301 para a versão sem `www` e testar no Search Console/Inspeção de URL.
